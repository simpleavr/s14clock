This is a web synchronized clock featuring 24 characters [and 12 characters](https://www.tindie.com/products/29601/) 14 segment LED displays, allowing spelled word time display options, plus various numeric character sets. The clock offers various display formats and options. Ad-hoc messages can also be posted to the clock unit via a built-in web server. Script integration (ex. curl) can easily be done to expand usages.

A single tactile button is used to advance one of the eight preset display formats / messages. The same button when press-n-hold allows cycling between various display transition effects.

A countdown timer can also be activated via double tapping the button. Setup is done via a web interface that allows for 8 preset display formats / messages.

By itself, S14Clock shows time and other preset messages. With its built-in web interface, scripts can be created and expand its usage such as stock tickers, POS display, weather forecast, etc. This is an open source PlatformIO / Arduino project that can be cloned or expanded into other projects.

Please refer to the **[S14Clock github project page](https://simpleavr.github.io/s14clock/index.html)** for **detailed setup and operating instructions**.

### **Main Features**


- Web based WIFI setup, upon initial usage.
- Web based configuration, to preset up to 8 display formats or messages.
- Date time formats via strftime() c library standard.
- Ad-hoc message via web page posting.
- Synchronize date time via NTP time server, with optional time zone / daylight saving (POSIX TZ) setup.
- Various settings including automatic cycling of messages, display transition effects, alternate numeric symbols, etc.
- Employs ESP32 S2 Mini, with open source code via my **[github repository](https://github.com/simpleavr/s14clock)**.
- Firmware updates by user via webtools, or over WIFI (OTA) from the clock's own web page.

### **Technical Details**

- Employs the WiFiManager library (captive portal) for entering WIFI credentials.
- Full use of ESP32 S2 Mini IO pins to perform LED multiplexing.
- Access of IO registers directly and timer interrupts for efficient multiplexing.
- S14-24 dimension 200mm x 32mm x 30mm, 100g.
- S14-12 dimension 100mm x 30mm x 30mm, 50g.
- Both units consume about 100mA at 5V.
- Power via USB-C, power supply and cable not included.
- V3 hardware design introduced since July, 2023. 74HC154D line decoder eliminated via additional charlieplexing on top of segment multiplexing.
- Current firmware (V2.04) able to auto-detect all versions of hardware, including V3, V2 12 and 24 characters.

### **Before You Order**
**This is a parts kit and will require soldering and assembly**, if you do not possess the tools and skills to construct it, select the "assembly" option. All parts are DIP through hole, there are no SMD parts to solder.

Two versions of **[12 (S14-12)](https://www.tindie.com/products/29601/)** and 24 (S14-24) characters were created, with same functionality. **This product is the 24 character version**.

Both S14-12 and S14-24 units have red LED modules. **S14-24 has dimmer display** as the multiplexing frequency is half that of the 12 character version. Both units' display intensity is adequate for indoor use.
